Veröffentlichung (GitHub)

Optional: Trägst du hier die Zugangsdaten zu einem GitHub-Repository ein (gehostet z. B. über GitHub Pages), erscheint bei jeder Kategorie und bei den Zuschlägen zusätzlich ein Button „🚀 Veröffentlichen", der die Datei direkt im Repository aktualisiert — ohne manuellen Download/Upload. Ohne diese Einrichtung funktioniert „Exportieren" + manuelles Ersetzen im Hosting weiterhin wie gewohnt.

Sicherheitshinweis: Das Zugriffstoken wird nur lokal in diesem Browser gespeichert, aber im Klartext — wer Zugriff auf dieses Gerät hat, könnte es auslesen. Verwende daher unbedingt ein fein-granulares GitHub-Token (Fine-grained personal access token), das nur auf dieses eine Repository beschränkt ist und dort nur die Berechtigung „Contents: Read and write" besitzt, sowie ein Ablaufdatum. Nie ein Token mit vollem Konto-/Repo-Zugriff hier eintragen.

Produktkatalog je Kategorie

Diese Seite hat keine Datenbank: Damit alle Mitglieder denselben Katalog sehen, lädt der Shop die Daten bei jedem Aufruf aus den data/*.csv-Dateien deines Hostings. Ein Upload hier zeigt dir erst eine lokale Vorschau in diesem Browser. Um sie für alle sichtbar zu machen: „Exportieren" klicken und die heruntergeladene Datei im Hosting unter dem angegebenen Pfad ersetzen (z. B. per FTP oder Git-Push), dann neu deployen.

Zwei Formate werden erkannt: entweder die Spalten ArtikelNr, Bezeichnung, Hersteller, Land, Qualitaet, Gebinde, PreisInklMwst, EntMwst, MwstSatz — oder direkt der Export aus Bodans Bestellsystem mit ArtNr, Bezeichnung, Hersteller, Land, Qualität, Gebinde, EK Ladeneinheit, EK VPE, UVP, EAN, MwSt (der Netto-Einkaufspreis „EK VPE" wird dann automatisch um die MwSt. hochgerechnet). Ein Upload ersetzt nur die jeweilige Kategorie.

Prozentzuschläge

Rücklage, Bankkosten, Fahrtkosten); zusammen ergeben sie den Gesamt-Zuschlag, der auf den Bodan-Preis inkl. MwSt. aufgeschlagen wird. Namen und Prozentsätze lassen sich direkt bearbeiten.
